# Cinefy 

Cinefy is a movie review platform allowing users to browse movies, view details, and manage reviews with real-time rating updates.

## Tech Stack
- **Frontend:** React + Vite
- **Backend:** NestJS + MongoDB (Mongoose)

## How to Run

### 1. Backend
*Ensure MongoDB is running locally on port 27017.*

cd backend
npm install
npm run start:dev
`

### 2. Frontend
*Open a new terminal window.*

cd frontend
npm install
npm run dev
`

Visit the link shown in the terminal (e.g., http://localhost:5173) to view the app.
